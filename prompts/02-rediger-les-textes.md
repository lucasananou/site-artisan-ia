# 02 — Rédiger les textes à partir d'un appel avec l'artisan

```
Voici mes notes brutes d'un appel avec [PRÉNOM NOM], [MÉTIER] à [VILLE] :

"""
[COLLER LES NOTES OU LA TRANSCRIPTION ICI]
"""

Écris les textes du site à partir de ces notes SEULEMENT. Si une information n'y est pas,
laisse un crochet [à demander : ...] plutôt que de combler.

Pour chaque élément, donne-moi le texte prêt à coller, avec le fichier et la section :
1. index.html — titre h1 (5 à 8 mots, avec le mot à mettre en <em> coloré),
   sous-titre (1 phrase), les 3 repères du héros, les 4 lignes du bandeau.
2. index.html — les 3 cartes de prestations : titre, 1 phrase, 3 puces.
3. index.html — les 3 étapes du déroulé de chantier, adaptées à CE métier.
4. a-propos.html — le parcours en 2 paragraphes, écrits à partir de ses mots à lui,
   et les 3 engagements concrets qu'il tient réellement.
5. services.html — pour chaque prestation : 1 paragraphe + les 4 lignes de faits.
6. Les <title> et <meta description> des 4 pages publiques.

RÈGLES D'ÉCRITURE
- Phrases courtes. Verbes d'action. Vouvoiement.
- Zéro superlatif, zéro « savoir-faire », « passion », « à votre écoute », « sur mesure »
  employé comme argument vide.
- Un fait concret vaut mieux qu'un adjectif : « un appel la veille pour confirmer l'heure »
  plutôt que « ponctualité ».
- Chaque section se termine par un chemin vers le téléphone ou le devis.
- Aucun chiffre, aucune durée, aucune garantie qui ne soit dans mes notes.
```
